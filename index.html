Hace falta un servidor

Este proyecto usa Vite y no se puede abrir con doble clic sobre index.html. Desde la carpeta del proyecto ejecuta:

# instalar dependencias (solo la primera vez)
npm install

# iniciar el servidor de desarrollo
npm run dev

Se abrirá el navegador en http://localhost:5173.
